

# Users & Posts Dashboard

## Project Overview
A Next.js application that displays user profiles and their associated posts using the JSONPlaceholder API.

## Features
- Fetch and display user profiles
- Search and sort users
- View posts for selected user
- Pagination for posts
- Responsive design

## Technologies Used
- Next.js 13
- React Query
- Tailwind CSS
- TypeScript

## Setup Instructions
1. Clone the repository `cd my-app`
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open http://localhost:3000
5. live url https://userspostsdashboard.vercel.app/
## State Management
Using React Query for:
- Efficient data fetching
- Caching
- Error handling
- Loading states

## Bonus Features
- Search functionality for users
- Sorting users by name/company
- Pagination for posts
